# Contributing to ClearComm911

ClearComm911 is currently in the architecture and planning phase. Contribution guidelines will be published when the first implementation is ready for collaboration.

In the meantime, if you have domain knowledge in any of the following areas and want to be involved early, please open an issue:

- PSAP operations and dispatch workflows
- CJIS compliance and public safety data handling
- SIP/VoIP telephony and audio stream integration
- Speech-to-text in real-time or low-latency environments
- Machine translation in high-stakes or safety-critical contexts

All contributions will follow conventional commits and a PR-based workflow with branch protection on `main`.
